# UNIX/Linux Engineer (Kernel Engineer) Volunteer is needed

Company Description

Procyberian Systems Distribution (PSD) is a Free Software GNU/Linux distribution based on the Debian GNU/Linux Operating System which is focused on security and stability. PSD is committed to Free Software principles and community-driven development, providing a secure and stable platform for users.

Role Description

This is a volunteer remote role for a UNIX/Linux Engineer (Kernel Engineer) at Procyberian Systems Distribution. Linux kernel knowledge and experience is critical for our needs. But we want from our members to be open minded and learn other UNIX OSes, Windows and other Free Software OSes or proprietary OSes. Because we want to write our own UNIX called PSD.

Qualifications

Experience in Linux Kernel development, especially writing code with Assembly Languages, C, C++ and Rust.
Strong problem-solving and analytical skills.
Excellent written and verbal communication skills.
Ability to work independently and remotely.
Experience with Free Software software development is a plus.
Bachelor's degree in Computer Science, Information Technology, or related field.
We will train newcomers whether they know kernel programming or not.
